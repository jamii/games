*Flag*. Passive. Can't move or be moved more than one space per turn.

*Walk*. Active. Move to the empty space in front of you.
*Run*. Active. Move to the empty space one space in front of you.
*Push*. Active. Move target unit one space away from you, and move into the space previously occupied by the target unit.
*Pull*. Active. Move target unit into your space, and move yourself into the empty space in the opposite direction.
*Swap*. Active. Swap places with target unit.
*Lift*. Active. Move target unit to an adjacent empty space.
*Jump*. Active. Move into the empty space on the opposite side of target unit.
*Climb*. Active. Move on top of target unit.
*Catapult*. Active. If in your home space, move to any empty space (not an enemy home space).
*Bungee*. Active. Move to an empty home space.
*Circle*. Active. Move to an empty space adjacent to the target unit.
*Rush*. Active. Move forwards in a straight line until blocked by another unit or the edge of the board.
*Burrow*. Active. Move to any empty space that is not adjacent to any unit.
*Leader*. Passive. Whenever this unit moves or is moved, move an adjacent unit into the empty space left behind, if possible.

*Heavy*. Passive. At the end of your turn, each unit within two spaces is moved one space towards this unit, if possible.
*Stinky*. Passive. At the end of your turn, each adjacent unit is moved one space away in a straight line, if possible.

*Trade*. Active. Swap a power with target unit. Can't give them a power that they already have.
*Stun*. Active. Remove a power from target unit.
*Trigger*. Active. Activate one active power of target unit as if it belonged to this unit.
*Mystery*. Active. Replace this power with a power from your hand.
*Fast*. Passive. Can activate this unit twice per turn.

*Reach*. Passive. Target a unit one space away.
*Spin*. Passive. Target all adjacent units.
*Beam*. Passive. Target all units in front of you.
*Chain*. Passive. Target all connected units.
*Halo*. Passive. Target all units exactly one space away.
*Colorblind*. Passive. Target all neutral units.
*Liability*. Passive. Target all friendly units.
*Bully*. Passive. Target all outnumbered units.
*Stalker*. Passive. Target all units that have no adjacent units.
*Spotlight*. Passive. Target all units adjacent to the *Flag*.
*Vengeance*. Passive. Target all enemy units that killed one of your units last turn.
*Six-shooter*. Passive. Target the nearest unit in each of the six directions.

*Bridge*. Passive. Any two units adjacent to this unit count as adjacent to each other.
*Telepath*. Passive. This unit is adjacent to all friendly units.

*Dogpile*. Active. If the target unit is outnumbered, kill it.
*Backstab*. Active. If there is a friendly unit on the opposite side of the target unit, kill the target unit.
*Click Click*. Active. Either add a token to this unit, or remove a token and kill the target unit.
*Neutralize*. Active. Kill all powerless units on the board.
*Explosive*. Passive. If this unit is killed, kill target unit.
*Spiky*. Passive. If this unit is moved by another unit, kill that unit.
*Banish*. Active. Move target unit to an empty home space.

*Split*. Active. Create a friendly unit in the space in front. Give it any number of this units powers.
*Trail*. Passive. Whenever this unit moves or is moved, and leaves behind an empty space, put a powerless neutral unit in that space.
*Convert*. Active. Replace the target neutral unit with a friendly unit with the same powers.

*Pacifist*. Passive. While this unit is adjacent to the *Flag*, units that is killed by a power instead returns to an empty home space, if one exists.
*Recycle*. Passive. While this unit is adjacent to the *Flag*, when you would return one of your powers to the deck, return it to your hand instead.
*Mine*. Active. If adjacent to the *Flag*, draw a power.
*Vacuum*. Passive. While this unit is adjacent to the *Flag*, any powers removed from the board are applied to this unit.
*Nuke*. Active. If adjacent to the *Flag*, either add a token to this unit, or remove 3 tokens and kill every unit on the board.

*Strong*. Passive. Count as 1 extra unit for scoring/outnumbering.
*Weak*. Passive. Target unit counts as 1 less unit for scoring/outnumbering.
*Grip*. Passive. Target unit can't move itself, but can still be moved by other units.
*Jammer*. Passive. Target unit can't activate active powers.
*Forbid*. Active. Name a (non-free) power. The opponent can't apply or activate that power on their next turn.
*Phoenix*. Passive. If this unit is killed by a power, place it in an empty space in your home.
*Recall*. Active. Kill the target friendly unit and return its powers to your hand.
*Stubborn*. Passive. This unit can't be moved (but can still move).

*Possess*. Active. Move this units powers onto target unit, then kill this unit.
*Lifeguard*. Passive. Target unit cannot be killed by a power.
*Friendly*. Passive. Target neutral unit counts as friendly for scoring/outnumbering.
*Twitchy*. Passive. Whenever an enemy unit becomes adjacent to this unit, immediately rotate this unit to face it.
*Remote*. Passive. When this unit activates a power, it may activate from the space of any friendly unit instead.
